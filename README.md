# CALISTRAX

### A structured guide to learning calisthenics skills.

Calistrax is a project I built to organize calisthenics skills into a simple progression-based guide.

Instead of just showing a list of skills, the idea is to show **what goes into learning a skill** — the warm-up, prerequisites, drills, and common mistakes to look out for.

## What it includes

* 12 calisthenics skills
* Difficulty-based skill organization
* Skill search
* Warm-up guidance
* Prerequisite checklists
* Skill-specific drills
* Common mistakes
* Interactive skill details
* Automatic sorting by difficulty

## Skills

It includes skills ranging from foundational movements to highly advanced skills such as:

* L-Sit
* Skin the Cat
* Pike Push-Ups
* Back Lever
* Muscle Up
* Handstand
* Front Lever
* Swing Gainer
* Handstand Push-Up
* Planche
* Human Flag
* One Arm Handstand

## Tech Stack

* HTML
* CSS
* JavaScript

I kept this project intentionally simple and focused on getting the core experience.I built it using plain HTML, CSS and JavaScript instead of React or another framework.

## How it works

The skill information is stored as JavaScript data and dynamically displayed on the page.

Users can:

1. Browse the available skills
2. Search for a specific skill
3. Open a skill to view its details
4. Go through its prerequisites
5. Explore drills and common mistakes

Skills are automatically organized according to their difficulty level.

I wanted to build something around a topic I actually enjoy while also getting more hands-on experience with frontend development.

Calistrax started as a simple HTML/CSS/JavaScript project, but the goal is to eventually take the idea further as I learn more technologies.
